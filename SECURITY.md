# Security Policy

## Supported Versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a Vulnerability

Use the repository's **Security** tab and select **Report a vulnerability** to
send a private report. Do not open a public issue for an unpatched security
problem.

Include the affected version, impact, reproduction steps, and any suggested
mitigation. Please allow time to investigate and prepare a coordinated fix
before publishing details.
